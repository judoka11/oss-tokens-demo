# Contributing to tiny-slug

Bug reports, tests and fixes are welcome. Run the tests with `npm test` (Node 18+, no install needed).

## AI-assisted contributions

We welcome AI-assisted help, on these terms:

- **Say so.** Mark AI-assisted comments and patches as such, and name the model.
- **A human stands behind it.** You've read what you post, you think it's right, and you'll answer questions about it.
- **Keep it short.** A five-line repro beats a page of analysis. No filler.
- **Don't guess.** If you didn't run it, say so. Never invent output.
- Issues labelled `ai-help-wanted` are open to donated agent time through [oss-tokens](https://github.com/judoka11/oss-tokens); see `.github/ai-tasks.yml` for which kinds of tasks.
